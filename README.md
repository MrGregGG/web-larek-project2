
# WEB-ларёк — проект №2

## Что добавлено по сравнению с main

- Реализованы модели каталога, корзины и заказа.
- Добавлен `ShopApi` для загрузки товаров, проверки данных сервера и отправки заказов.
- Добавлена система событий `EventEmitter` и координатор `createApp` для взаимодействия частей приложения.
- Реализованы просмотр карточек товаров, добавление и удаление товаров из корзины.
- Добавлены автоматический подсчёт количества товаров и общей стоимости.
- Реализовано двухэтапное оформление заказа с проверкой заполнения форм.
- Добавлена обработка ошибок сервера и защита от повторной отправки заказа.
- Реализовано сохранение данных корзины и формы при неудачной отправке заказа.

## Запуск проекта

Требуется Node.js и npm.

Установить зависимости:

```bash
npm ci
```

Запустить проект:

```bash
npm start
```

Файл .env создаётся автоматически при запуске проекта, если он ещё не существует.

Открыть в браузере: http://localhost:8080/
